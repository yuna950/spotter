# SPOTTER

지역별 관광지와 축제 정보를 한눈에 확인할 수 있는 여행 정보 웹앱

---

## 기획 의도

기존 여행 정보 서비스에서 원하는 여행지를 찾기 위해 여러 정보를 각각 검색해야 하는 점이 불편했습니다.

SPOTTER에서는

메인 화면에서 추천 관광지를 바로 확인하고
지역을 선택해 해당 지역의 관광지를 탐색하고
축제 및 행사 정보를 함께 확인할 수 있도록

'검색 → 탐색'보다 '발견 → 탐색'에 초점을 맞춘 여행 정보 서비스를 구현했습니다.

---

## 주요 기능

### 메인 페이지

- 랜덤 추천 관광지 Hero
- 지역별 관광지 큐레이션
- 전국 축제·행사 정보 Swiper
- 테마별 여행 콘텐츠

### 지역별 관광지

- 지역별 관광지 조회
- 관광지 이미지 및 기본 정보 제공
- 지역별 상세 페이지 이동

### 축제·행사

- 2026년 축제 및 행사 정보 조회
- 축제 이미지 / 지역 / 기간 / 장소 제공
- 축제 상세 페이지 제공

### 상세 페이지

- 관광지 상세 정보
- 축제 상세 정보
- 이미지 및 주소 등 상세 데이터 제공

## 느낀점 & 배운점

### 반응형 작업

pc 화면을 기준으로 작업하다보니, 진행될수록 반응형 작업에서 수정해야 할 부분이 많아지고 실수도 발생했다. 모바일 화면을 먼저 기준으로 잡고 작업을 시작하고 화면 크기에 따라 키워가는 방식이 좀 더 효율적일거라는것을 배웠다.

### 라우팅 설계

사용한 API에서 지역 코드와 시군구 코드가 별도로 사용된다는 점을 라우터 설계 단계에서 충분히 생각하지 않고 개발을 시작했다. 그로인해 광역시 지역 데이터는 잘 불러와지는데 시군구 데이터가 제대로 불러와지지 않는 오류가 발생했다. IA를 설계할 때 화면 구조 뿐만아니라 실제 API의 데이터 구조와 요청 경로까지 모두 고려하는게 중요하다는 것을 알게 되었다. 다음 작업부터는 API의 데이터 구조를 꼼꼼히 파악하고 라우팅 설계를 할 것이다.

### 파라미터 활용

contentTypeId 값을 변경하여 하나의 API에서 관광지와 축제 등 서로 다른 유형의 데이터를 불러올 수 있다는걸 배웠다. 좀 더 간단하고 효율적으로 API를 활용할 수 있는 방법을 익힐 수 있었다.
