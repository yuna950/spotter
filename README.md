# SPOTTER

지역별 관광지와 축제 정보를 한눈에 확인할 수 있는 여행 정보 웹앱

---

## 주요 기능

- 지역별 관광지 조회
- 관광지 목록 및 상세정보
- 축제 목록 및 상세정보
- 두루누비 여행 코스 정보 조회
- 키워드 검색

---

## 사용한 기술

- React 19.2.8
- React DOM 19.2.8
- Vite 8.2.0
- Tailwind CSS 4.3.3
- React Router DOM 7.18.2
- Swiper 14.1.0
- React Icons 5.7.0
- React Loader Spinner 8.0.2
- Iconify Griddy Icons
- ESLint
- VS Code

---

## 사용된 API

- 한국관광공사\_두루누비 정보 서비스\_GW
  - 여행 코스 정보를 조회하여 코스 여행 콘텐츠로 활용
- 한국관광공사\_관광지별 연관 관광지 정보
  - 관광지와 연관된 관광 정보 조회에 사용
- 한국관광공사\_국문 관광정보 서비스\_GW
  - 관광지와 축제 기본 정보 및 상세 정보 조회에 사용
